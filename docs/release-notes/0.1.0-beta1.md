# Legacy Discord 0.1.0-beta1

Mac OS X 10.6 Snow Leopard 〜 OS X 10.8 Mountain Lion 向けの、ネイティブ (AppKit) の Discord クライアントです。
公式クライアントの見た目と操作に近づけることを目標にしています。今回はボイスチャットを含まない最初のベータ版です。

## 動作環境

- Mac OS X 10.6.8 〜 OS X 10.8.5(64 ビットの Intel Mac)
- OS X 10.9 Mavericks は「動けば良い」程度のサポートです
- インターネット接続(TLS はアプリ内蔵の curl / OpenSSL で行うため、古い OS でも Discord に接続できます)

## インストール

1. `LegacyDiscord-0.1.0-beta1-x86_64.zip` をダウンロードして展開します。
2. `Legacy Discord.app` を「アプリケーション」フォルダに移動します。
3. 初回は Control キーを押しながらクリック →「開く」で起動してください(開発元未確認のアプリのため)。
4. メールアドレスとパスワード、またはトークンでログインします。トークンは macOS のキーチェーンに保存されます。

## 主な機能

- サーバー・チャンネル・スレッド・フォーラム・ダイレクトメッセージの閲覧と送信
- 返信、編集、削除、リアクション、絵文字・スタンプ、ファイル添付(最大 10 ファイル / 10 MB)、ネタバレ
- 検索、ピン留め、プロフィールのポップアウト、メンバーリスト、フレンド一覧
- 公式風のサーバーメニュー(サーバー名の ▼):招待、サーバー設定、チャンネル/カテゴリーの作成、通知設定、サーバープロフィール編集、ミュートしたチャンネルを非表示、サーバーから脱退
- 公式風の右クリックメニュー(サーバー、チャンネル、カテゴリー、メッセージ、メンバー)とダイアログ
- サーバー一覧のホバーでサーバー名を表示
- 設定:マイアカウント、コンテンツ&ソーシャル、テーマ、ユーザー補助、チャット、通知、キー割り当て、言語、詳細設定
- 日本語 / 英語の切り替え(設定 › 言語。既定はシステムの言語に合わせます)
- テーマ:ダーク、ミッドナイト、オーロラに加え、公式 Nitro と同じ 22 種類のカラーテーマ(グラデーション)
- 通知:Dock バッジ、Dock アイコンのバウンス、通知音、通知センター(10.8 以降)
- 画像・アバター・絵文字のディスクキャッシュ(最大 200 MB、設定から削除可能)

## 既知の制限

- ボイスチャット・画面共有は今回のリリースには含まれていません(10.8 以降向けに開発中です)。
- ライトのカラーテーマでは、リアクションボタンが macOS 標準の見た目のままです。
- AquaProxy などの HTTPS プロキシ経由でしか通信できない環境では接続できません。DNS が使えるネットワーク設定が必要です。
- 未翻訳の文言が一部英語のまま残っている場合があります。
- Discord の非公式クライアントです。利用は自己責任でお願いします。

# Legacy Discord 0.1.0-beta1 (English)

A native AppKit Discord client for Mac OS X 10.6 Snow Leopard through OS X 10.8 Mountain Lion that aims to look and
work like the official client. This is the first beta, without voice chat.

**Requirements:** Mac OS X 10.6.8 – OS X 10.8.5 on a 64-bit Intel Mac (OS X 10.9 is best effort). TLS uses the bundled
curl and OpenSSL, so the app connects to Discord on old systems.

**Install:** unzip, move `Legacy Discord.app` to Applications, and open it the first time with Control-click › Open
(the app is not from an identified developer). Log in with your email and password or a token; the token is kept in the
Keychain.

**Highlights**

- Servers, channels, threads, forums and direct messages: read and send, reply, edit, delete, reactions, emoji and
  stickers, attachments (up to 10 files / 10 MB), spoilers, search, pins, profiles, member list and friends.
- The official server menu under the server name, official context menus and dialogs, and server name bubbles on hover.
- Settings: My Account, Content & Social, Appearance, Accessibility, Chat, Notifications, Keybinds, Language and Advanced.
- Japanese and English UI (Settings › Language; follows the system by default).
- Themes: Dark, Midnight and Aurora plus all 22 official Nitro color themes.
- Dock badge and bounce, mention sound, Notification Center banners on 10.8+, and a 200 MB image cache.

**Known limitations**

- No voice chat or screen sharing yet (in development for 10.8+).
- Reaction buttons keep the standard macOS look in light color themes.
- Networks that only work through an HTTPS proxy such as AquaProxy are not supported; working DNS is required.
- A few strings may still be in English.
- Unofficial client; use at your own risk.
