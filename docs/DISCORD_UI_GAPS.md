# 公式Discordとの見た目の差分（2026-10-15 調査）

方針: 公式Discordのダークテーマとレイアウトを、AppKit で軽量に再現する。

比較基準は 2023〜2024 年版デスクトップクライアントのダークテーマ。
`DLUtil` の配色（#1E1F22 / #2B2D31 / #313338 / #383A40 / #404249、
文字 #F2F3F5 / #B5BAC1、リンク #00A8FC）がすでにこの版と一致しているため。
2025 年の visual refresh 版は対象外（必要なら別途判断）。

根拠: `artifacts/snow-leopard/20261001-ui-debug/` の実機スクリーンショット
（rules-final-wide, friends-final-wide, codex-release-hover-narrow,
other-profile-card-final, release-picker-search）と現行コード。
公式側の寸法は記憶ベースのため、実装時に公式クライアントの画面で確認すること。

優先度: A = 一目で「Discordっぽくない」と分かる / B = 情報の欠落 / C = 細部

## A. 見た目の印象を大きく損ねているもの

| # | 箇所 | 現状 | 公式 | 実装メモ |
|---|---|---|---|---|
| A1 | スクロールバー（2026-10-15 対応済み、10.6.8 実機確認済み） | チャンネル一覧とチャット欄が Snow Leopard 標準の青い Aqua スクローラー | 細い（約8px）暗色の角丸スクローラー、トラックはほぼ不可視 | `NSScroller_BGColor` は既にあり、メンバー一覧などでは適用済み。チャンネル outline と `ChatScrollView` に未適用 |
| A2 | ポップアウト（絵文字・スタンプ・プロフィール）（2026-10-15 対応済み、10.6.8 実機確認済み） | Snow Leopard では標準タイトルバー付き NSPanel（"Legacy Discord" と表示） | 枠なし・角丸・影付きの浮動パネル | 10.6 でも borderless NSPanel + 自前描画の角丸背景で再現可能。`DLCompatibilityPopover` 1 か所の変更で全部に効く |
| A3 | ユーザー名の色（2026-10-15 対応済み、10.6.8 実機確認済み） | チャット・メンバー一覧とも白一色 | 最上位の色付きロールの色 | ロール色はプロフィール側にのみ実装あり。メッセージヘッダとメンバー行に展開 |
| A4 | メンバー一覧（2026-10-15 対応済み、10.6.8 実機確認済み） | "MEMBERS" 1 グループのみ、アルファベット順、状態表示なし | ロール別グループ「ロール名 — 人数」、ONLINE / OFFLINE、オフラインは半透明、アバターに状態ドット、2 行目にカスタムステータス | Gateway の `GUILD_MEMBER_LIST_UPDATE` の groups を利用。presence も必要 |
| A5 | メンバー一覧の選択行（2026-10-15 対応済み、10.6.8 実機確認済み） | 明るい灰色の背景 + 白文字（読めない） | ホバーや選択は #404249 程度の暗い角丸背景 | バグ寄り。プロフィール表示時に再現 |
| A6 | ウィンドウのタイトルバー（2026-10-15 対応済み、10.6.8 実機確認済み） | 標準の灰色 Aqua タイトルバー＋サーバー名 | 暗色の一体型タイトルバー | 10.6 では full-size content view が使えない。textured window で暗色描画するか、現状維持とするか要判断（リスク中） |

## すでに十分近いもの

- 3 ペイン構成と配色
- 40px アバターと、連続投稿のグループ化
- メンション背景、(edited) 表示、返信の接続線
- Twemoji による絵文字表示（Snow Leopard 標準の絵文字に依存しない）
- プロフィールカードの全体構成（バナー、アバター、ロール）

## 推奨する着手順

効果が大きく、Snow Leopard でのリスクが低い順。

1. A1 スクロールバー、A5 選択色: 既存部品の適用だけで済む
2. A2 ポップアウトの枠なし化: 1 か所の修正で 3 画面に効く
3. A3 ロール色、B1 日付区切り: メッセージ表示の共通部分の修正
4. B5 作成欄、B2 ユーザーパネル、C1〜C4 寸法の調整
5. A4 メンバー一覧のグループ化と状態（presence の受信が必要）
6. B6 Markdown の拡張
7. B7 サーバーレール、B8 DM ホーム、B9 絵文字ピッカー
8. A6 タイトルバー（方針判断が必要）

## 対応メモ（2026-10-15）

- A2: `DLCompatibilityPopover` を全 OS 共通の枠なし角丸パネルに変更（Lion 以降の NSPopover も使わない）。Esc で閉じる。
- A3: チャット欄とメンバー一覧でロール色を表示。REST で取得した履歴にはロール情報がないため、メンバー情報の受信後に色が付く。Gateway で届いた新着は即時に色が付く。
- B1: 日付が変わる位置に区切り線と日付を表示。`channel-message-states` 再現データに翌日のメッセージを追加。
- B5: 「+」を入力枠内へ移動し、`Message #チャンネル名` のプレースホルダを表示。
- 既存の不具合（今回の変更前から発生）: `channel-layout-attachment` の 720x520 で添付画像がチャット欄の右端からはみ出す。
- 実機確認（2026-10-15）で見つけて修正: プレースホルダとロールチップの絵文字が □ になる問題、ポップアウトを閉じた後のメンバー一覧の青いフォーカスリング。
- B2: 背景を一段暗くし、状態ドット、マイク・ヘッドホン（VC 未実装のため無効表示）を追加。
- C2〜C4: チャンネル行 32px、サイドバー 240px（保存済みの幅は一度だけリセット）、メンバー一覧 240px・アバター 32px。
- 設定画面: Web 版の構成（ユーザー設定 / アプリ設定）に変更。実際に効く項目のみ追加。使われていなかった旧プロキシ設定は表示しない。
- A4: 表示ロール別 → ONLINE → OFFLINE のグループ、在席ドット、カスタムステータス、オフラインの半透明表示。人数は読み込み済みメンバー（最大 500）から算出。
- B6: チャンネル／ロール／スラッシュコマンドのメンション、タイムスタンプ、見出し、小文字テキスト、箇条書き、マスクリンク、スポイラー（クリックで表示）。
